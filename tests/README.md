# tests

`tests/` is memex's test suite. The conformance suite in [cases](cases/README.md) is the behavioural spec: every behaviour is pinned there by a case. `conformance.rs` runs it through the shared runner in [harness](harness/README.md), and `runner_selftest.rs` checks the conformity rules against the deliberately broken trees in `runner-selftest/` (hidden from the walk by `.ignore`). `quality.rs` is the code-quality gate: file length, purpose headers, a README per folder, no lint escape hatches under `src/` and `tests/`, and no panicking call (`.unwrap()`, `.expect(`, `panic!` and kin) in `src/` outside test code. `selfhost.rs` runs the built memex on this repo, with real git and no `MEMEX_NOW`, and checks the repo's own intent layer: every source file has a header, every folder has a README, and no doc under `src/` has an unresolved citation. `stress/` is the opt-in stress suite, run with `cargo test --release --test stress -- --ignored` (see [stress](stress/README.md)).
