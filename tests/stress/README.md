# stress

`stress/` is memex's opt-in stress suite: the built binary run at scale, with concurrent writers, on fuzzed input, and against timing budgets. Every test in it is `#[ignore]`, so `cargo test --locked` runs none of them; run the suite with `cargo test --release --test stress -- --ignored`, and narrow it with a name filter such as `scale_`. `main.rs` lists the modules and holds the round-trip smoke test. `support.rs` is the shared code: the binary's path, scratch repositories with a scrubbed environment (`Sandbox`, `cmd`, `run_stdin`), a seeded tree generator (`write_tree`), and timings with the load average (`median_ms`, `min_ms`, `report`). `scale.rs`, `concurrency.rs`, `fuzz.rs` and `budget.rs` are the four families of tests, and each is a placeholder until its tests land. The suite cites no case ids (`Cases: none (stress)`): the conformance cases in [cases](../cases/README.md) pin behaviour, and a stress run measures how long that behaviour takes and whether it holds under load.
