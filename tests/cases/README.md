# cases

This folder is the conformance case hub. Each family is a folder here, such as `cli/`. It holds its own README.md, a CASES.md declaring the family's case ids and claims (ids like `SRCH-FUZZY-01`), and one folder per case, named by its id. The full convention is in PLAN.md §2; this hub is expanded when the runner lands in S0.2.
