# cli

The CLI family covers design §3 and §3.6: grammar, help, errors and exit codes. Its prefix is `CLI`. CASES.md declares the case ids, and each case is a folder named by its id. The grammar cases pin help after each verb, `--`, flags, positionals, bare `memex`, unknown verbs and the JSON error envelope; the exit codes 1 and 3 are planned for the REF, DISC and PORT families.
