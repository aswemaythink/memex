# discovery

The discovery family covers design §4.1: how `log` finds its root and its log store. Its prefix is `DISC`. The root is the nearest folder with a `.memex/`, searched no higher than the toplevel, the nearest folder listing a `.git` entry, with or without git (DISC-ROOT-05, TOP), else the toplevel, else the cwd. The store is the main checkout's `.memex/logs/` for a linked worktree, and `<git-common-dir>/memex/logs/` for a linked worktree of a bare repo; a `.git` folder or no toplevel keeps the root's own store, with no git asked for it (DISC-BAREDOT). The family also pins what creating the store writes, the layout fallback when git is missing or fails, and the config warnings of §4.1 item 4. Its cases observe `log` through its `--json` path, its stderr and snapshots of the store. DISC-WT-03 pins that a log from a linked worktree is pruned by the main checkout's `keep_logs`.
