# show

The show family covers design §3.3 and §3.6: what `memex show` prints for a file, a Markdown file, a folder, `.` and a log ref; its `--up` and `--limit` options; several refs; the partial failures that exit 1; and its `--json` document. Its prefix is `SHOW`. Each case is a folder named by its id, and each carries the same small intent layer as its fixture: a root README, a `src/` folder with a README, headers, a folder without a README, and one log entry. Cases that test a missing `.memex/` leave that folder out. SHOW-IO-01 is the unreadable requested file, and SHOW-IO-02 the requested folder that cannot be listed: its ref's io error, the other refs printed, and the exit code 1, in text and with `--json`. Its cases with a mode-000 file or folder set it with `chmod` in case.json, which is unix-only. SHOW-OTHER-01 is a file in a second root beside the cwd's, whose cites and cited by print the root in their place, and whose JSON gives them as null.
