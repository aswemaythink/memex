# manifest-kinds

The manifest-kinds family covers design §4.2's `folder` and `json` kinds: a marker file that defines one doc with its merged files, and an array whose entries are docs. Its prefix is `MANK`, and its topics are FOLDER and JSON. Its cases are built: each one is a real manifest in `.memex/collections/` that the loader of the `manifest` family reads, so `show` observes the docs and warnings. The unit tests in `src/collections/folder.rs` and `src/collections/json.rs` pin some of the same claims on temporary fixture trees. The S2.6 rulings that these cases pin are written into their claims, and two points remain pending: a marker or data file that does not parse gives no warning, and a folder whose marker lacks the field named by `id` gives no doc.
