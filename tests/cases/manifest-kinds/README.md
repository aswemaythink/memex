# manifest-kinds

The manifest-kinds family covers design §4.2's `folder` and `json` kinds: a marker file that defines one doc with its merged files, and an array whose entries are docs. Its prefix is `MANK`, and its topics are FOLDER and JSON. Its cases are planned, not built: the kinds are reached only through the manifest loader, which S2.4 lands in the `manifest` family (prefix `MAN`), so until then `show` cannot observe them. The unit tests in `src/collections/folder.rs` and `src/collections/json.rs` pin the same claims on temporary fixture trees, and each planned case gets its folder when the loader lands.
