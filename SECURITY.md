# Security policy

## Supported versions

Only the latest 0.x release gets security fixes. Older 0.x releases do not.

## Reporting a vulnerability

Report it privately with GitHub's [Report a vulnerability](https://github.com/aswemaythink/memex/security/advisories/new) form, which uses GitHub's private vulnerability reporting. Do not open a public issue or pull request about it, and do not send reports by email.

Include the memex version (`memex --version`), the command you ran and the smallest input that shows the problem. Maintainers reply in that advisory.
