# Concepts

`site/docs/concepts/` holds the concept pages: the ideas memex is built on, one page each. A concept page says what an idea is and why memex works that way; the guides and the reference say how to do the task.

- `intent-layer.html`: the READMEs, headers, collections and logs that say what code is for, and the order an agent reads them in.
- `compression.html`: authored compression, and why memex needs no server, database or model.
- `trails.html`: citations read both ways, logs for work in progress, and collections for what stays true.
- `drift.html`: how the layer falls behind the code, and what `memex audit` does and does not find.
