# Guides

`site/docs/guides/` holds the guides: how to work with memex day to day, one page per task. Each page gives when to use it, the steps and samples.

The pages are `hand-off.html` (hand-off and messages) and `drift.html` (checking drift). The sidebar's Guides section also lists `get-started.html`, which stays in `docs/`. Each new page also goes in `NAV` in `../docs.js`.
