Concepts

Three ideas carry memex. Each is short here; the intro page draws them.

The intent layer

Code records what a system does. The intent layer records what it is for: a README says why a folder exists, a header says what a file is for, a case says what is claimed and how it is proven, and a log says what an agent was trying and what it found.

memex reads intent, never code bodies. For symbols, rg is already the right tool.

See the intent layer on the intro page.

Authored compression

A README compresses a folder, a header a file, a case a test, a log an agent’s run. Whoever knew the most writes it, when they knew it best, so nothing has to summarise it later.

That is why memex needs no server, database or model: the compression was already done.

See Context compression on the intro page.

Trails

Citations are trails. An id, a path or a ref written in prose links two things, and memex reads every link both ways: what a doc cites, and what cites it.

Logs and collections let the next agent start where the last one stopped. Logs are work in progress and expire; whatever is still true gets written into the layer by someone who understands it.

See Trailblazing on the intro page, and the story for where the word comes from.
