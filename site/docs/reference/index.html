Verbs

Seven verbs, all read-only except init and log.

The verbs

memex init
Set memex up in a repo, once. Safe to repeat.
memex info
Where everything is: the graph, collections, log streams and messages waiting for you.
memex show
Read one thing’s intent, then walk its trail: what it cites and what cites it.
memex tree
The shape of a folder: its folders and files, their one-liners and how many files lack a header.
memex search
Find by words across READMEs, headers, collections and logs.
memex audit
List where intent is missing or a citation is broken.
memex log
Record a finding and hand back a one-line ref.

Shared by every verb

showing N of M
Every list says how much it printed, so nothing is cut silently.
--limit N
Raises or lowers a list’s cap.
--json
stdout becomes one JSON document, errors included.
--help
Works after any verb.

Configuration

The log store’s size cap and age limit live in .memex/config.json: see Configuration.

Exit codes

0
OK, zero hits included.
1
Not found or ambiguous.
2
Usage error.
3
Environment error, such as log with no .memex/.
