# Reference

`site/docs/reference/` is the reference, one page per verb. `index.html` lists the verbs, their shared conventions and the exit codes.

The verb pages are `init.html`, `info.html`, `show.html`, `tree.html`, `search.html`, `audit.html` and `log.html`; `configuration.html` covers `.memex/config.json`. Behaviour comes from DESIGN.md §3; change it there first.
