# Patterns

`site/docs/patterns/` holds the patterns: conventions that held up in practice, one page each. `index.html` introduces them; each page gives when to use it, the steps and samples. The day-to-day guides are in `../guides/`.

The pages are `cases.html`, `doom-hunts.html`, `perf-optimisation.html` and `promote-findings.html`. Each new page also goes in `NAV` in `../docs.js`.
