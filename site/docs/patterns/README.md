# Patterns

`site/docs/patterns/` holds the how-to guides, one page per pattern. `index.html` introduces them; each page gives when to use it, the steps and samples.

The pages are `cases.html`, `doom-hunts.html`, `perf-verdicts.html`, `hand-off.html`, `drift.html` and the anti-pattern `distill-logs.html`. Each new page also goes in `NAV` in `../docs.js`.
