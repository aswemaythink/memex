Patterns

Collections and log streams need no declaration, so the conventions are what matter. These are the ones that held up in practice.

Write it where the next reader will look

True of the code, it goes in a header or README. True of this run, a log. A claim a test proves, a case.

The patterns

Test cases
One file per claim, with an id the test carries.
Doom hunts
Try to break a module; leave a report either way.
Perf verdicts
Every optimisation tried, kept or cut.
Hand-off
Return a ref, not a report; messages are logs.
Drift
Check that the intent still matches the code.
Distill a log
Copying logs into a collection adds noise; write down what’s still true.
