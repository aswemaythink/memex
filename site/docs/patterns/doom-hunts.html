Pattern

Doom hunts memex: doom

An agent sent to break one module leaves one short report, break found or clean, so nobody re-proves a dead end.

When to use it

When you send an agent to try to break one module, and you want the next agent to start from what was already tried.

Steps

  1. Before hunting, search the collection for past hunts on the module.
  2. Hunt one gap at a time: a hypothesis, then a red test.
  3. End every hunt, break found or clean, in one short Markdown report with memex: doom frontmatter: the hypothesis and the red test, then the verdict.
  4. Name the report by date and slug, one gap per report.

A report

# doom/2026-09-20-jettison-namer-key-order.md
---
memex: doom
module: atomic/namer
theories_spent: 2
verdict: clean-hunt
---
# Namer key order survives reordered declarations

Search past hunts

# past hunts on this module
memex search namer key --in doom
# frontmatter keys are filters
memex search verdict:break-found --in doom
memex show doom:2026-09-20-jettison-namer-key-order
