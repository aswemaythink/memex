# cite

`src/cite/` holds the parts of `cite.rs` that find citations and backlinks (design §2.3): the tokenizer, the resolver that turns a doc's tokens into the docs and entries they name, and the index that a verb asks for. `search`'s roster takes the full index; `show` takes one index for all the targets it prints, so a `show` of many refs scans every doc's tokens once and reads only those that can name one of them.

- `tokens.rs`: reads a line of a doc's text as tokens, each borrowed from the line: links, `collection:id` labels, `X-*` prefixes and words, and tells a case id from other text. `index.rs` gives it only the lines outside fenced code, which `../fence.rs` finds. A link destination in angle brackets is read to its `>`, so it may hold spaces.
- `paths.rs`: resolves the tokens of a doc (design §2.3): a path token or a markdown link from the citing doc's folder and then from the root, never above the root; a label, a bare id or a prefix against the names of the scan (`Names`). It also gives a target's one-liner, and `Wanted`, the filter of a targeted scan: a token is resolved only when it can name one of the targets, so a `show` skips the rest. The filter's tests are necessary conditions (its header states them), so every hit of each target is found. `last_name` is the name that a path ends in, which the filter checks before a path is resolved.
- `index.rs`: `build` records each target's backlinks for every doc, which is `search`'s roster. `for_show` gives the `show` sections of several targets their backlinks, and the cites of their docs, by the same resolver as `build`. It scans every doc's tokens once, on several threads, and resolves in full only the cites docs. A self-citation is dropped, and a prefix citation is a backlink marked with its prefix, and never a cite. `direct_count` counts a target's backlinks without the prefix ones, which is the `<-N` of a `search` roster. A link or path token that names a manifest doc's file cites the doc by its `collection:id` label, unless an intent doc holds that file; `manifest_label` gives `show <path>` that label from the doc paths alone, without an index (design §2.3).
