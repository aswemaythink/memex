# intent

The readers of the intent layer (design §2). `header.rs`, with its `header/` folder, reads a file's leading comment block, and `readme.rs` gives a README's doc and one-liner. `front.rs` reads a Markdown file's `memex:` frontmatter (design §2.2): it reads the head once, and gives the file's one doc, or its entries when it is an entry index. `entries.rs` reads an entry index's items into entry docs. `files.rs` picks the reader for each walked file and gives its docs and warnings; a file with no comment family has no header, so it is never opened and gives no warning (design §4.2). `mod.rs` holds the rule they share, the paragraphs of a block and the one-liner, which is the first sentence of its first paragraph, and `Origin`, which says where each doc was read from.
