# intent

The readers of the intent layer (design §2). `header.rs`, with its `header/` folder, reads a file's leading comment block, and `readme.rs` gives a README's doc and one-liner. `front.rs` reads a Markdown file's `memex:` frontmatter (design §2.2): it reads the head once, and gives the file's one doc, or its entries when it is an entry index. From the same head it gives the file's title, which its folder's child line shows (design §3.3). `entries.rs` reads an entry index's items into entry docs. `files.rs` picks the reader for each walked file and gives its docs, warnings and Markdown title; a file with no comment family has no header, so it is never opened and gives no warning (design §4.2). `mod.rs` holds the rule they share, the paragraphs of a block and the one-liner, which is the first sentence of its first paragraph; `Origin`, which says where each doc was read from (a log entry is its own origin, so a collection named like a stream is never a log, and a folder doc notes whether its marker is Markdown); `by_label`, which groups the docs by label; and the `Doc` predicates that tell the graph's READMEs and headers apart from a collection of the same name, and `cites_fields`, which says whether a doc's frontmatter fields are cited (design §2.3). `shared.rs` warns of each collection that shares a name with the graph or a log stream (design §4.2 Names), names the file it starts in, and finds the duplicate ids of the collections (design §2.2).
